# Sprint 7 — API-тестирование Яндекс Самоката

## Описание проекта

Проект посвящён автоматизации API-тестирования сервиса Яндекс Самокат
В рамках проекта реализованы автотесты для основных API-эндпоинтов сервиса с использованием `pytest` и `requests`
Для формирования отчёта о результатах тестирования используется Allure

## Технологии

  Python 3.13
  ytest 9.1.1
  requests
  Allure
  allure-pytest 2.16.2

## Тестируемые эндпоинты

### Создание курьера

`POST /api/v1/courier`

Проверяются следующие сценарии:

  создание курьера с корректными данными
  создание курьера с уже существующим логином
  создание курьера без логина
  создание курьера без пароля
  создание курьера без имени

Всего: 5 тестов

### Авторизация курьера

`POST /api/v1/courier/login`

Проверяются следующие сценарии:

  авторизация с корректными данными
  авторизация с неверным паролем
  авторизация без логина
  авторизация без пароля
  авторизация несуществующего курьера

Всего: 5 тестов

### Создание заказа

`POST /api/v1/orders`

Проверяется создание заказа с различными вариантами поля `color`:

  `BLACK`
  `GREY`
  `BLACK` и `GREY`
  без поля `color`

Всего: 4 теста

### Получение списка заказов

`GET /api/v1/orders`

Проверяется успешное получение списка заказов.

Всего: 1 тест

## Запуск тестов

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить все тесты:

```bash
python -m pytest -v
```

Ожидаемый результат:

```text
15 passed
```

## Формирование Allure-отчёта

Запустить тесты с сохранением результатов для Allure:

```bash
python -m pytest --alluredir=allure-results
```

Открыть отчёт:

```bash
allure serve allure-results
```

После выполнения команды Allure откроет отчёт в браузере

## Известный дефект

В тесте авторизации курьера без пароля (`test_login_courier_without_password`) ожидается ответ `400` с сообщением `Недостаточно данных для входа` согласно документации API.

Фактически API возвращает `504 Gateway Timeout`.

Тест помечен как `xfail`, дефект фиксируется в автоматизированных тестах, но не приводит к падению всего тестового набора.
